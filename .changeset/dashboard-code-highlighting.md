The dashboard's code snippets are syntax-highlighted: the install snippet (HTML, Next.js), the redirect rules on a broken link (`_redirects`, Vercel, Next.js, Nginx, Apache) and every agent's MCP setup (shell commands, JSON configs, the auth header). Long lines prefer to wrap at spaces rather than mid-word, and code no longer draws `<>` or `/>` as ligatures. Agent prompts stay plain text.
