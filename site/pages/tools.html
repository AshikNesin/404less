Free tools

Fix the redirect. Then stop doing it by hand.

Five small tools for the jobs that show up mid-deploy: generate a 301, convert _redirects to vercel.json, see a redirect chain, tell a real 404 from a soft 404, or scan a site for broken links. No account. The same code 404less uses when you host it yourself.

301 redirect generator

htaccess, Netlify, Vercel, Nginx

Paste old → new URLs, a _redirects file or vercel.json. Get rules for every host, and a warning when a splat, a slash or a 308 will make them miss.

Redirect chain checker

Every hop, status and loop

Enter a URL. We follow it server-side and flag chains, loops, and a hop that switches between http and https.

404 / soft 404 checker

Real 404, or a 200 that pretends

Compare your URL with a path that should not exist. This is the Search Console “Soft 404” warning, checked on the response rather than the template.

Broken link checker

A short crawl, no signup

Crawl up to 60 pages. Broken links and redirect chains, with robots.txt, timeouts, and no requests to private addresses.

GitHub Action

Fail CI on open broken links

A workflow that reads the links your self-hosted crawler already found and fails the job when any are still open.

Run the same checks on a schedule.

404less is these tools, plus the 404s real visitors hit, a redirect rule for each one, and alerts. Self-host it on Cloudflare’s free tier.
